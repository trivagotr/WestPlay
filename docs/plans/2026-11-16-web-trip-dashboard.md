# Web sürüş ve sefer paneli

Yalnız web arayüzü değişir; oyun GPS Konvoy katmanı korunur. Sağ Konvoy listesi kaldırılır. Sol panel tüketim(L/100km), menzil, tek toplam hasar(bütün beş SDKbileşeni varsa ortalama), cruise sabit hızı ve65km/sa eşikli şerit hazır/aktif renklerini gösterir. Sinyaller gerçek SDKlamba fazını ayrı50ms güncelveri akışıyla izler; CSSyanıp-sönme uydurulmaz. Tam ekranda alttaki araç/klavye kontrolleri gizlenir.

Sağ sefer paneli otobüste memnuniyet/yolcu sayısı, tırda yük hasarı; hedef, planlanan varış/teslim saati ve gecikme alanlarını taşır. SDKvermediği alanlar çizgi olarak kalır. Kamyon iş yapılandırmasındaki city/deadline kullanılır; bus_job belgelenmemiş özellik ad/tipleri sınırlı tanı loguyla öğrenilir, değerler tahmin edilmez. Gerçek şerit aktif kanalı bulunmadan yeşil varsayılmaz.

Ana köprü29 değiştirilmez; ek SDKkanalları ayrı süreç kimlikli dashboard MMF kullanır. Oyun çalışırken eklenti değiştirilmez/oyun kapatılmaz. Yeni paket kurulumu ve canlı yolcu işi doğrulaması sonraki adım. APK değişmez.
